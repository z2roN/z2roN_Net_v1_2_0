# z2roN_Net (네트워크 정보 보기) v1.2.0
안드로이드와 **윈도우**에서 내 네트워크 상태를 한 화면에 보여주는 앱 (Flutter, 플러그인 없음).

- 외부(공인) IP, 국가·통신사
- 연결 방식(무선 Wi-Fi / 유선 이더넷 / 모바일), Wi-Fi 이름(SSID), BSSID, 주파수, 신호 세기, 연결 속도(링크 속도)
- 내 IP, DNS, 게이트웨이(공유기) + [공유기 접속] 버튼(브라우저로 http://게이트웨이 열기)
- 속도 측정: 다운로드 / 업로드 / 응답(핑) (Cloudflare 속도 측정 서버 사용)
- 내 기기: 기기 이름, 제조사/모델, 운영체제 버전(Android 는 API, Windows 는 빌드 번호), 커널
- 같은 네트워크 기기 검색: IP, 이름(공유기가 알려주는 경우), 종류·운영체제(열린 포트로 추정)
- 빌드: .github/workflows/build.yml (GitHub Actions) - Android APK, Windows 설치 파일(exe) + 압축 파일(zip)

## 한계
- 안드로이드는 다른 기기의 MAC 주소·운영체제를 직접 알려주지 않아 운영체제는 '추정'입니다.
- Wi-Fi 이름은 위치 권한을 허용하고 휴대폰 위치 기능이 켜져 있어야 보입니다.
- 공유기가 기기 간 접속을 막으면 기기 검색에 나오지 않을 수 있습니다.

## v1.2.0 - 윈도우 버전
- 같은 화면·같은 기능을 윈도우에서 사용할 수 있습니다. (Windows 10 / 11, 64비트)
- 윈도우에서는 안드로이드용 코드(MainActivity.kt) 대신 `lib/bridge.dart` 가 PowerShell 과 `netsh` 를 실행해서 같은 형태의 정보를 만듭니다.
  - 연결 방식(Wi-Fi/유선/VPN 등), IP·DNS·게이트웨이, 연결 속도(Wi-Fi 는 받기/보내기), Wi-Fi 이름·BSSID·신호·채널·주파수
  - 내 기기: 컴퓨터 이름, 제조사/모델, Windows 이름·버전·빌드
  - 주변 Wi-Fi 목록(`netsh wlan show networks mode=bssid`), 공유기 접속(기본 브라우저)
- 윈도우 빌드 방법 (안드로이드와 같은 방식)
  1. 이 프로젝트 전체(.github 폴더 포함)를 GitHub 저장소에 올립니다.
  2. Actions > "z2roN_Net 빌드" > Run workflow
  3. 몇 분 뒤 Artifacts 의 **z2roN_Net-windows-v버전** 을 내려받습니다.
     - `z2roN_Net_Setup_v버전.exe` : 설치 파일. 더블클릭 → 설치 (관리자 권한 불필요, 바탕화면 바로가기 선택 가능)
     - `z2roN_Net_windows_v버전.zip` : 설치 없이 압축을 풀어 `z2ron_net.exe` 를 실행
  - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행] 을 누르세요. (서명하지 않은 프로그램이라 나오는 정상 경고입니다)
- 윈도우 한계
  - Wi-Fi 이름이 안 보이면 Windows 설정 > 개인정보 및 보안 > 위치 에서 위치 서비스를 켜세요. (Windows 11 최신 버전은 위치 서비스가 꺼져 있으면 netsh 가 Wi-Fi 정보를 주지 않습니다. 이때는 연결 프로필 이름을 대신 보여줍니다)
  - 같은 네트워크 기기 검색은 안드로이드와 같은 방식(열린 포트 확인)이라 MAC 주소는 보이지 않고 운영체제는 '추정'입니다.
  - 주변 Wi-Fi 목록은 윈도우가 보관한 최근 검색 결과일 수 있습니다.
  - 이 프로젝트는 개발 환경에 Flutter 가 없어 윈도우 빌드를 직접 컴파일해 보지 못했습니다. 첫 빌드가 빨간 X 로 끝나면 해당 단계의 마지막 로그를 알려주세요.
